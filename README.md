# Flow

Landing page conceitual de uma bebida energética para mentes criativas, feita como projeto de estudo do Método ID, da @natdesigner, que combina construção com IA e direção criativa humana.

**[Ver o site publicado](https://taislacerda19.github.io/flow-site/)**

A Flow não é uma marca real. Preços, sabores e formatos são demonstrativos: não há compra, pagamento nem coleta de dados.

## Como foi feito

O site foi construído com IA, seguindo as etapas do método e usando os materiais fornecidos no curso. Isso significa que marca, referências e parte dos arquivos visuais vêm desse material de estudo, e não são criação própria.

- **Código:** um único `index.html`, sem framework e sem etapa de build.
- **Performance:** imagens em WebP e fontes locais em WOFF2.
- **Publicação:** GitHub Pages, servindo a raiz do repositório.

## Como rodar

Baixe o repositório e abra `index.html` no navegador. Não é preciso instalar nada.

## Fontes

Barlow Semi Condensed e Google Sans Flex, sob a licença SIL Open Font License. Os arquivos das licenças estão na pasta `fontes/`.
